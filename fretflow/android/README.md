# Fretsky — Instant Android SDK APK Builder (No Gradle Required)

## Build in 3 Seconds on Windows
1. Extract this ZIP archive into `C:\Users\Mitch\Documents\Fretsky` (replacing existing files).
2. Double-click **`build_apk.bat`**.
3. This script bypasses Gradle completely and calls your local Android SDK tools (`aapt2`, `javac`, `d8`, `zipalign`, and `apksigner`) directly to output **`Fretsky.apk`** in about 3 seconds.
